# Transformer Pipeline

This directory contains all the original source code for the experiments in this project. It includes the scripts for data preprocessing, the definitions of the transformer models, and the main script for training and evaluating the models.

## Directory Structure

```
Transformer_Pipeline/
├── Preprocessing/
│   └── Load_Data.py
│   └── Cyber_Trend_to_Graph.py
└── Cyber_Trend_Graph_Dataset.py
└── Models/
    └── example_model.py
```
## Preprocessing Scripts

The Preprocessing subdirectory contains the scripts for loading and transforming the raw cyber threat data into formats suitable for the transformer models.

* **`Preprocessing/Load_Data.py`**:
    * Provides a reusable function (`load_cyber_threat_data`) to load the raw `Cyber_Trend_Forecasting_All.csv` file.
    * Handles date parsing and sets the 'Date' column as the DataFrame index.
    * Performs basic validation (checking file existence, sorting data).

* **`Preprocessing/Cyber_Trend_to_Graph.py`**:
    * Imports the loading function from `Preprocessing/Load_Data.py`.
    * Contains the main pipeline steps to convert the loaded time-series DataFrame into a graph-based format suitable for spatio-temporal graph models.
    * Responsibilities include: chronological splitting, graph structure definition (adjacency matrix), data normalisation, creating time-series windows, and saving the final processed files (adjacency matrix, windowed data, scaler).

## Dataset Scripts

* **`Cyber_Trend_Graph_Dataset.py`**:
    * Defines a custom PyTorch `Dataset` class (e.g., `CyberThreatGraphDataset`) for the graph data.
    * Responsible for loading the **processed** data files (e.g., `.npz`, `.npy`, `.pkl`) generated by `Cyber_Trend_to_Graph.py`.
    * Implements the required `__init__`, `__len__`, and `__getitem__` methods.
    * Includes logic (based on constructor arguments) to optionally run the full preprocessing pipeline on-the-fly (less efficient alternative).
    * * The `__getitem__` method retrieves a single sample (input window and target window) by index and returns them as PyTorch tensors, ready for the `DataLoader`.
